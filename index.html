Verbindung

Die App verbindet sich direkt mit deinem Gira HomeServer im Heimnetz und zeigt dessen Räume und Geräte.

Home Assistant führt viele Marken (Hue, tado, Shelly, Homematic IP und mehr) zusammen. Zuhause zeigt alles an einem Ort.

So verbindest du deinen HomeServer
  1. Voraussetzung. Gira HomeServer oder FacilityServer mit Firmware 4.10 oder neuer, mit aktiver IoT-REST-API (Version 2). Ob sie bei dir freigeschaltet ist, klärt dein Elektriker oder der Gira Project Assistant.
  2. Adresse. Trage die IP-Adresse des HomeServers ein, zum Beispiel 192.168.1.20. Dein Handy muss im selben WLAN sein.
  3. Zertifikat. Öffne die Adresse einmal in Safari und bestätige die Sicherheitswarnung. Der HomeServer nutzt ein selbst ausgestelltes Zertifikat.
  4. Anmeldung. Nimm einen Benutzer aus deinem Gira-System. Das Passwort wird nicht gespeichert, die App merkt sich nur einen Zugangsschlüssel.
  5. Auf den Home-Bildschirm. In Safari auf Teilen tippen, dann Zum Home-Bildschirm.

Der Zugangsschlüssel bleibt nur auf diesem Gerät gespeichert.

So verbindest du Home Assistant
  1. Zentrale installieren. Home Assistant läuft auf einem kleinen Gerät im Heimnetz, zum Beispiel Home Assistant Green oder einem Raspberry Pi.
  2. Geräte hinzufügen. In Home Assistant unter Einstellungen, Geräte und Dienste, die Marken auswählen, die du besitzt.
  3. Token erstellen. In Home Assistant auf dein Profil tippen, ganz unten bei Sicherheit ein langlebiges Zugriffstoken anlegen und hier einfügen.
  4. Adresse eintragen. Für den Zugriff von unterwegs braucht die Adresse https. Am einfachsten geht das mit Home Assistant Cloud. Eine reine http-Adresse blockiert iOS auf dieser Seite.
  5. Auf den Home-Bildschirm. In Safari auf Teilen tippen, dann Zum Home-Bildschirm.

Das Token bleibt nur auf diesem Gerät gespeichert.
